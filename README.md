# 🚀 Selenium Automation Framework

A Java-based Selenium Automation Framework developed to automate web application testing using industry best practices such as the **Page Object Model (POM)**, **TestNG**, and **Maven**.

## 📖 Overview

This project was built as part of my Software Testing learning journey to strengthen my automation testing skills and apply real-world QA practices.

The framework focuses on writing clean, maintainable, and reusable automation scripts while following standard test automation architecture.

## 🛠️ Technologies Used

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)
* WebDriverManager
* IntelliJ IDEA
* Git & GitHub

## ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/abdo659/SeleniumAutomation.git
```

Navigate to the project:

```bash
cd SeleniumAutomation
```

Run the tests:

```bash
mvn clean test
```
